# Simple Shell

A Unix shell written in C. Team project by Blessed Tasela and Alade, built during the ALX programme in May 2023.

It reads commands, parses them, and runs them: builtins, external programs, environment variables, command history, and exit handling.

## Stack

C · Unix system calls

## Build and run

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o hsh
./hsh
```
